# 🚀 Dinamik Portfolyo & Admin Yönetim Paneli

Modern ziyaretçi arayüzü, güçlü içerik yönetimi ve detaylı istatistikleri tek projede buluşturan **ASP.NET Core MVC** tabanlı dinamik portfolyo uygulaması.

---

## ✨ Proje Hakkında

Bu proje, modern tasarım anlayışıyla geliştirilmiş, tamamen yönetilebilir bir **Portfolyo ve Admin Yönetim Paneli** uygulamasıdır.

Ziyaretçiler portfolyo içeriklerini inceleyebilir, projeleri görüntüleyebilir, iletişim formu üzerinden mesaj gönderebilir ve sosyal medya hesapları üzerinden iletişime geçebilir.

Yönetici paneli sayesinde tüm içerikler kod değişikliği yapmadan kolayca yönetilebilir.

# ⚙️ Kurulum

```bash
git clone https://github.com/KULLANICI_ADIN/Case1Protfolyo.git
```

### Kurulum Adımları

1. Projeyi bilgisayarınıza klonlayın.
2. SQL Server üzerinde veritabanını oluşturun.
3. Connection String bilgisini güncelleyin.
4. Entity Framework Migration işlemlerini çalıştırın.
5. Projeyi başlatın.
