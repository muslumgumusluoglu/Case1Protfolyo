# 🚀 Dinamik Portfolyo & Admin Yönetim Paneli

Modern ziyaretçi arayüzü, güçlü içerik yönetimi ve detaylı istatistikleri tek projede buluşturan **ASP.NET Core MVC** tabanlı dinamik portfolyo uygulaması.

---

## ✨ Proje Hakkında

Bu proje, modern tasarım anlayışıyla geliştirilmiş, tamamen yönetilebilir bir **Portfolyo ve Admin Paneli** uygulamasıdır.

Ziyaretçiler portfolyo içeriklerini inceleyebilir, iletişim formu üzerinden mesaj gönderebilir ve sosyal medya bağlantılarıyla iletişime geçebilir. Yönetici paneli sayesinde tüm içerikler kod değişikliği yapmadan kolayca yönetilebilir.

---
